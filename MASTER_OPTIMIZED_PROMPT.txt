Mathematical Modeling & Evaluation Metrics:
- Execution Time: ET_ij = (Task Instructions_i) / (VM MIPS_j)
- Completion Time: CT_vm_j = sum(ET_ij for all tasks on vm_j)
- Makespan (Eq. 7): max(CT_vm_j) for j = 1..m (Objective: Minimize)
- Average Resource Utilization (ARU, Eq. 8): (sum(CT_vm_j) / m) / Makespan in [0, 1] (Objective: Maximize)
- Throughput (Eq. 9): (Total Tasks) / Makespan (tasks/second) (Objective: Maximize)
- Average Response Time (RT, Eq. 10): Average task waiting time before execution starts.
- Algorithm Execution Time: Runtime of the scheduler in milliseconds.

Base Paper Algorithm (PEWOA - Algorithm 1):
- Population: 60 whales, 220 iterations.
- Modified Encircling Parameter (Eq. 16): a = 3.0 - itr * (2.0 / maxItr) [ranges from 3.0 down to 1.0].

- Encircling and Bubble-net attack: p >= 0.5 triggers spiral update, p < 0.5 with |A| >= 1 triggers random whale exploration, |A| < 1 triggers best whale encircling.
- Parallel Architecture: Master-slave thread pool using Java Executor Framework (Executors.newFixedThreadPool) updating shared memory global best with synchronization locks.
